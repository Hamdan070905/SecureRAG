How to Apply the Fix cleanly:
Close the running app: Make sure the white/blank window of "SecureRAG Enterprise" is completely closed (check Task Manager if needed to ensure it isn't running in the background).

Run the new installer:

Go to D:\Secure RAG\frontend\dist-electron\

Double-click SecureRAG Enterprise Setup 1.0.0.exe

Follow the installation steps to overwrite the old installed version.

Launch the updated app: Open it from your desktop shortcut or Start Menu—the white screen issue will now be fixed!
